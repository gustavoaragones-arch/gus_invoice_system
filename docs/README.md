# Documentation Index

## Phase 0 — Requirements Baseline

The documents in [`phase-0/`](phase-0/) constitute the **Phase 0 requirements baseline** for the Canadian Private Billing System. They were produced under a Phase 0 requirements-audit mandate: no application code, database schema, or architecture was created in this phase — only the documented specification below.

These documents **precede architecture**. Architecture (Phase 2) and every implementation phase after it must satisfy the requirements, constraints, and scope boundary documented here. **Implementation must not begin until the Project Director reviews and authorizes the next phase.** Several material decisions remain explicitly unresolved (see [11-unresolved-decisions.md](phase-0/11-unresolved-decisions.md)) and are handed to the Project Director rather than assumed.
